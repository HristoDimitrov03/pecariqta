# Пецарията | Pecariqta — Sofia

Marketing site for **Пецарията | Pecariqta**, a wood-fired Neapolitan pizzeria in Sofia — Vite + React + TypeScript + Tailwind.

## Run locally

```bash
npm install
npm run dev
```

Dev server: **http://localhost:3022/**

## Logo

The restaurant logo lives at `public/images/logo.png` (brick-oven arch with a flame mark).

## Scripts

| Command | Description |
| ------- | ----------- |
| `npm run dev` | Start Vite dev server |
| `npm run build` | Production build |
| `npm run preview` | Preview production build |
| `npm run lint` | Typecheck |
